Before you double-click

Unsigned, for now

Early builds have no code signature yet. Windows: SmartScreen → More info → Run anyway. macOS: right-click the app, choose Open, then Open again. Only download from this page.

Your desk stays yours

Keys, transcripts and workspace files stay on your computer. The office works offline with the demo provider, and an account is optional.

No key? No problem

Try the office offline first.

Install a build, open it, and choose Demo mode in setup. The Bits use scripted offline replies: no API key, no account, no network. Switch to your own key whenever you want real model calls.
