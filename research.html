From-Scratch 740M Foundation Model (OMI-740M v1.0-PoC): Pre-Training Convergence, Layer Separation, and Hardware Benchmark Protocol

1. Scope & Pre-Training Methodology — Unlike LoRA fine-tunes or adapter wrappers built on third-party weights, OMI-740M v1.0-PoC was initialized from random Gaussian weights and pre-trained on single-node A100 infrastructure across a 4.0-billion-token Proof-of-Concept corpus. Training completed in native bfloat16 precision with a final cross-entropy validation loss of 1.842.

2. Separation of Model vs. Host Agent Harness — To ensure scientific clarity, this report separates neural weight capabilities from external software tooling:
• Model Weights (OMI-740M): Generates code diffs, Chain-of-Thought reasoning tokens, and structured JSON arguments.
• Local Inference Runtime: Executes 4-bit Q4_K_M quantized GGUF weights within ~984 MB RAM.
• Host Agent Harness (v0.4): Enforces GBNF context-free grammars on model outputs and executes sandboxed local shell/file tools.

3. Known Boundaries & Phase-2 Target — At the 740M / 4B-token PoC scale, the model achieves high reliability on single-file diffs and 1–3 step tool calls within an 8K active context window. Multi-file repository refactoring across >8K tokens requires host-level chunking and is the primary target of our planned OMI-1B v2.0 (1B parameters / 100B tokens) multi-GPU run.
