Features

Cute on the outside.
Serious tools inside.

GoBits is a real agent app, not a toy. Every Bit has tools and memory, and every action leaves a trail you can inspect.

Real tools, on your machine

Bits read and write files, fetch web pages and run commands inside a workspace folder you choose. Nothing executes in the cloud.

You approve what matters

Commands and risky writes pause for a cozy dialog: allow once, for this order, or always. Chained shell commands always ask.

Projects & checkpoints

Point an order at a project. Each run saves a checkpoint, so you can diff every file and revert in one click.

Run & preview

Start your app from the Run panel and open the live preview. Stop shuts down the whole process tree.

Build your office

Privacy & security

Your keys. Your files. Your call.

GoBits runs a small server on your own computer. Your AI provider talks to it directly, and so do you.

  • Keys stay with youYour API key goes from your computer straight to the provider you picked, never to us. Exports never include it.
  • A sandboxed workspaceBits can only touch files inside the folder you choose. Path escapes are rejected, and web fetches can't reach your private network.
  • Approvals by defaultShell commands ask first. Chained commands such as a && b always ask and can't be set to "always allow".
  • Locked to localhostThe local server listens on 127.0.0.1 only and checks every request's host and origin.

Never leaves your computer

  • Your API keys
  • Agent transcripts and tool output
  • Files in your workspace and projects
  • Commands and their output

Optional GoBits Cloud only syncs your office layout, Bits and order history, plus anything you choose to share. It never runs tools or sees your keys. Commands you approve run with your user's permissions, so use a dedicated folder.

FAQ

Questions from the break room

What exactly is GoBits?

GoBits is a desktop-style web app that runs on your computer. It turns an AI agent system into a pixel office: a lead Bit plans each order and delegates to specialist Bits, which use real tools to do the work. You watch it happen, approve what matters and collect the results from the Delivery Box.

Which AI models does it work with?

DeepSeek, OpenAI, xAI (Grok), Anthropic, or any OpenAI-compatible endpoint, including local models. A scripted mock provider lets you try the whole office offline with no key at all.

Do I need an account?

No. Guest mode works fully offline on your computer. An optional, invite-only GoBits Cloud account adds office sync across devices and read-only share links.

What does it cost?

Early access is invite-only, and pricing for the optional cloud features isn't final yet. You bring your own API key and pay your provider directly for usage. GoBits shows an estimate for every order and can enforce a daily budget cap.

Can the Bits break my computer?

Bits work inside a workspace folder and ask before running commands or making risky changes. Every run saves a checkpoint you can diff and revert. Approved commands do run with your user's permissions, so point GoBits at a dedicated folder and review requests before you allow them.

What do I need to run it?

Windows, macOS or Linux with Node.js 18 or newer. There's no npm install: start the local server and open the office in your browser.

Can I share what my Bits made?

Yes. With a cloud account you can create a read-only link to your office or to a finished order, and revoke it at any time. Shared pages never include keys, transcripts or files unless you explicitly attach one.
