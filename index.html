01 // SYSTEM ARCHITECTURE

Three Distinct Engineering Layers.

We strictly separate what is learned inside the neural weights, what is executed by the local inference runtime, and what is orchestrated by the host agent harness.

HIERARCHY // WEIGHTS → RUNTIME → HARNESS
LAYER 01 // WEIGHTS OMI-740M

From-Scratch Pre-Training

Learned in Weights: Neither an open-weight clone nor a LoRA adapter. OMI-740M is initialized from scratch on A100 GPUs (4B tokens PoC) with a custom tokenizer to learn code syntax, Chain-of-Thought steps, and JSON function arguments natively.

LAYER 02 // RUNTIME ~1 GB VRAM

Zero Data Leak & ~1 GB Footprint

Handled by Runtime: Quantized to 4-bit GGUF (Q4_K_M), the inference engine allocates ~984 MB of local RAM/VRAM. It executes 100% offline on consumer laptops and edge GPUs with zero external network sockets or API costs.

LAYER 03 // HARNESS AGENT + CODE

Agent & Code Execution Loop

Orchestrated by Host Layer: While OMI-740M emits structured tool calls and unified diffs, our external host runtime enforces grammar constraints (GBNF), validates JSON schemas, and executes sandboxed terminal commands.

02 // EMPIRICAL BENCHMARKS

Local Runtime vs. Cloud API.

Eliminating network round-trips removes WAN latency and external data exposure, while local compute requires upfront prefill processing (TTFT) on edge silicon.
